## 1. 작업 개요

2026년 6월 최종 발표 이후 OpenAI API 키·쿼터 문제와 네이버 뉴스 API 경로 변경 등으로 재실행이 되지 않았다. 실행 환경을 Gemini 기반으로 옮기고, 실데이터로 9개 Agent를 하나씩 점검하면서 발견한 로직 문제를 고쳤다.

| 구분 | 6월 최종본 | 11월 수정본 |
|---|---|---|
| LLM | OpenAI `gpt-5.4-mini` | Google Gemini `gemini-2.5-flash-lite` (`services/llm_client.py`) |
| 뉴스 API | `openapi.naver.com` | 네이버 클라우드 API Hub (`naverapihub.apigw.ntruss.com`) |
| 분석 대상 | 코스닥 시총 상위 N개 (업종 무관) | 코스닥 **바이오·제약 4개 업종** 중 시총 상위 N개 |
| 공시 분류 | 1년치 제목을 이어 붙여 단어 포함 여부 검사 | 제목 1건씩 분류 + 해제·정정·기술적 거래정지 제외 |
| R&D 비중 | 못 찾으면 10.0% 기본값 | 사업보고서 본문·주석에서 추출, 없으면 `데이터 없음` |
| Cash Runway | 현금흐름 0 이상 또는 결측이면 24개월 | `현금 소진 없음` / `데이터 없음` / 개월 수 구분 |
| 결과 저장 | 없음 (매번 재분석) | `.cache/saved_reports.json` 저장·불러오기 |

## 2. 수정 내역

### 2.1 실행 환경

- **LLM 교체**: News·Supervisory·Report Writer·산업분석 스케줄러가 공용 `llm_client.py`를 통해 Gemini를 호출하도록 변경. Gemini 응답이 리스트 형태로 올 때를 처리하는 `message_text()` 추가
- **네이버 뉴스**: NCP API Hub 주소와 `X-NCP-APIGW-API-KEY` 인증 헤더로 변경
- **분석 대상 필터**: FinanceDataReader `KRX-DESC` 업종표로 바이오·제약 업종만 남긴 뒤 시가총액 순으로 선정. LLM 호출 전 단계에서 걸러 토큰 낭비 방지. 업종표를 못 받으면 분석하지 않음
- **KIPRIS**: `ServiceKey` 파라미터 추가, API 오류코드 처리, 페이지당 건수(numOfRows)를 특허 수로 잘못 읽던 버그 수정

### 2.2 공시 리스크 오탐 수정 (`dart_client.py`, `disclosure_agent.py`)

| 문제 | 원인 | 조치 |
|---|---|---|
| 알테오젠 공시 HIGH | 무상증자에 따른 매매거래정지가 '거래정지'로 매칭 | 기술적 매매거래정지(무상증자·액면분할·주식병합·이전상장·신주상장 등) 제외 |
| 같은 날 제출한 유상증자 4건이 '반복'으로 판정 | 제출 건수 기준 | 서로 다른 날짜 2건 이상일 때만 '유상증자 반복' |
| 해제·정정 공시도 위험으로 반영 | 단어 포함 여부만 검사 | `해제`·`철회`·`미지정`·`정정` 포함 제목 제외 |
| 불성실공시 지정예고도 HIGH | 단어 포함 여부만 검사 | 지정 확정만 HIGH, 지정예고는 MEDIUM |
| DART 조회 실패가 MEDIUM으로 반영 | 오류 문구가 키워드 목록에 섞임 | `data_errors`로 분리 → 조회 실패는 MEDIUM(60점) + `disclosure_data_missing` 특이 케이스로 전문가 검토 |
| 1년치 공시 일부 누락 | 100건만 조회 | 최대 5페이지(500건) 조회 |

상세 페이지에 걸린 공시 제목·날짜·반영/제외 사유를 표로 보여주도록 추가했다.

### 2.3 재무 데이터 기본값 제거 (`dart_client.py`, `financial_agent.py`)

- **R&D 비중**: DART 재무제표 API에는 연구개발비가 별도 계정으로 나오지 않는 경우가 대부분이라 모든 기업에 10.0%가 들어가고 있었다. 이 때문에 '계획된 적자 보정'(R&D 20% 이상 조건)이 실제로는 한 번도 적용되지 않았다.
  - 1순위: 사업보고서 '연구개발활동' 표의 연구개발비/매출액 비율 (% 기호가 없는 표, 종속회사 N/A 행 처리)
  - 2순위: 재무제표 주석 '연구개발비의 기능별 배분' 합계 ÷ 매출액
  - 사업보고서 원문은 `.cache/dart_reports/{corp_code}_{연도}.zip`으로 캐시
  - 끝까지 못 찾으면 배점 중간값(5.5점) + `R&D 데이터 확인 불가`
- **Cash Runway**: 영업현금흐름 결측도 0으로 처리되어 24개월이 들어가던 문제 수정. `BURN`(개월 수 계산) / `NO_BURN`(현금 소진 없음) / `UNKNOWN`(데이터 없음)으로 구분
- **영업현금흐름 결측**: 중간값(8.5점) + `영업현금흐름 데이터 확인 불가`

### 2.4 Supervisory · 뉴스 · 보고서

- 강한 부정과 중간 부정 키워드가 섞여 Supervisory에 전달되던 버그 수정 (`app.py`). 삼천당제약의 '계약 해지'가 강한 부정으로 잘못 표시되던 문제 해결
- A 등급도 공시 조회 실패 시 전문가 검토로 전달
- LLM 실패 시 뉴스 병합 가중치를 `키워드만 (LLM 미반영)`으로 표시
- Report Writer: A·B·C 등급만 Gemini로 작성, D·E·부결은 템플릿 (쿼터 절약)
- 상세 페이지에 회사별 LLM 호출 상태(뉴스·Supervisory·보고서) 표시

### 2.5 시연 편의

- 분석 완료 시 결과를 `.cache/saved_reports.json`에 저장, `USE_SAVED_REPORTS=true`면 서버 시작 시 불러옴
- 대시보드 제목·하단 문구를 실제 분석 기업 수로 표시

## 4. 남은 이슈

| 이슈 | 내용 | 상태 |
|---|---|---|
| 부채비율 | 유동비율이 6~7배인 휴젤·파마리서치도 부채비율이 110~144%로 계산됨. 계정 매칭(`부채총계`/`자본총계`) 확인 필요 | 확인 필요 |
| 바이오 점수 상한 | 임상 7건·특허 11건 이상이면 같은 점수, 임상 중단은 건수와 무관하게 −15 → 휴젤·삼천당제약·HLB 모두 70.0 | 개선 예정 |
| 임상 검색 별칭 | `apatinib`(HLB), `botulinum toxin`(휴젤) 같은 일반명이 다른 회사 임상까지 포함할 수 있음 | 개선 예정 |
| Gemini 쿼터 | 무료 등급으로는 5개사 1회 실행이 한계. 50개사는 유료 플랜 필요 | 운영 이슈 |
| 기존 테스트 | `test_*.py`는 6월 구조 기준이라 이번에 실행하지 않음 | 정리 필요 |
| 산업 분석 | `scheduler/market.py`는 파이프라인 미연결 | 보류 |
